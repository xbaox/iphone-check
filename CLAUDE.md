# iphone-check

Одностраничный PWA-чеклист проверки iPhone. Всё в index.html; sw.js — network-first, версию кеша не бампать.

## Правила
- Перед КАЖДЫМ коммитом обновить `APP_VERSION` в index.html на текущие дату и время (формат `YYYY-MM-DD HH:MM`). Без этого у пользователей не появится плашка «Обновить».
- Дизайн-систему (цвета, шрифты, отступы, скругления) не менять без явной просьбы.
- Тексты пунктов чек-листа выверены по документации Apple — не «улучшать» формулировки.
- Пуш в `main` напрямую, один коммит на задачу, сообщение на русском.
- Коммиты подписывать noreply-адресом GitHub (см. `git config user.email`), иначе пуш отклонит защита GH007.
- Перед пушем поднять локальный сервер (`python -m http.server 8000`), открыть http://localhost:8000: консоль без ошибок, счётчик пунктов совпадает с данными. Файл двойным кликом не открывать — Chrome пишет ложные CORS-ошибки.
