# Проверка iPhone · Чек-лист

PWA-чек-лист для проверки iPhone при покупке (БУ и новый).

**Возможности:**
- ✅ Интерактивные галочки с сохранением прогресса (localStorage)
- 📱 Устанавливается на главный экран как приложение (PWA)
- 🌐 Работает оффлайн после первой загрузки (Service Worker)
- 🌙 Тёмная тема, адаптивный дизайн под телефон

## Деплой на GitHub Pages

1. Создай репозиторий на GitHub, например `iphone-check`
2. Загрузи все файлы в корень репо
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)`
4. Сохрани — через минуту сайт будет на `https://USERNAME.github.io/iphone-check/`

## Добавить на главный экран (iPhone)

1. Открой ссылку в **Safari** (не Chrome!)
2. Кнопка «Поделиться» → **На экран Домой**
3. Готово — иконка появится как приложение

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Вся логика и разметка чек-листа |
| `manifest.webmanifest` | PWA-манифест |
| `sw.js` | Service Worker (оффлайн-кеш) |
| `icon-*.png` | Иконки для главного экрана |
| `.nojekyll` | GitHub Pages без Jekyll-обработки |
